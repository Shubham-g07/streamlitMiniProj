# PeoplePulse

A creative Streamlit employee-management dashboard using SQLite.

## Features

- Sidebar pages: team display, employee CRUD, salary graphs, and company info
- Persistent SQLite database seeded with 20 employees
- Add, view, update, and delete employees using an action dropdown
- Search, domain filters, and CSV export
- Bar, donut, and interactive scatter salary charts

## Run

```powershell
.\flaskstreamlit\Scripts\streamlit.exe run app.py
```

The database file (`peoplepulse.db`) is created automatically on the first run.
